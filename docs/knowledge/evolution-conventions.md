# Curated evolution and health conventions

Scope: supported Phase 6 implementation. Evidence and limits: [operating guide](../evolution.md), [ADR 0014](../decisions/0014-controlled-knowledge-skills-and-health.md), [phase plan](../phase-6-plan.md).

- Keep source syntax, human observation, actual native evidence and inferred intent distinct. Source hashes plus available revisions establish freshness, not business truth.
- A temporary failure is not a permanent procedure. Repeated unchanged ingestion should not create another mandatory explanation. Curated records remain concise and source-backed.
- Knowledge approval, native execution trust, skill-evaluation trust, activation and reversal are separate grants. Record exact hashes and retain unknown/unavailable evidence honestly.
- Progressive knowledge lookup must stay within the original repository/file scope. Its approved hashes are task dependencies; revocation invalidates earlier generation work.
- Evaluate actual observable bundle behavior. A valid SKILL.md or matching words do not prove good decisions. Fixed deterministic script comparison does not replace a general agent trial.
- Summaries can group repeated findings only when root, fingerprint and severity remain distinct and evidence/occurrence counts are preserved. Original findings retain their full actions and uncertainty.
- Directory-level skill publication prevents discovery of a partially written bundle. Journals and hidden backups support explicit recovery; they do not authorize overwriting concurrent instructions.
- Health completion is different from passing tests or a clean system. Unknown dynamic consumers, mutable data, stale indexes and missing checks cannot become confident absence claims.
- Report known provider totals once, null unknown usage and labelled byte proxies. Publish the actual comparison inputs, denominators and evidence class before claiming improvement.

These are curated development notes. Product knowledge is stored privately; neither this document nor any runtime observation activates a user skill.
